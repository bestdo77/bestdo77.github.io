# bestdo77.github.io

Personal GitHub Pages site for Xinghang Yu. The site is a zero-build static page with bilingual content, responsive layout, light/dark themes, and print styles.

## Local preview

    python3 -m http.server 4173

Then open <http://127.0.0.1:4173/>.

## Files

- `index.html`: content and semantic page structure
- `styles.css`: editorial layout, responsive rules, themes, and print styles
- `app.js`: language/theme persistence, mobile navigation, active sections, and reading progress
- `assets/`: existing portrait and paper assets
