03.1

Parallel Model Eviction for a Large-scale Parameter Server

2026 · C++ · PARAMETER SERVER · AOF + SSD TIERED STORAGE

BYTEDANCE · INFRA
  • Ordered concurrency: introduced per-region coordinators that keep the append-only log and SSD write path strictly ordered while eviction runs across many threads.
  • ~35% faster: parallelized the eviction hot path while keeping the single-thread path as a safety fallback, with near-flat memory and virtually no extra disk I/O.
  • Correctness first: verified dump files by bit-exact, per-FID comparison across single-threaded, multi-threaded, and concurrent-model runs — zero mismatches.

03.2

Incremental Management & Real-time Classification of Astronomical Light Curves

2025.03 — 2026.06 · TDENGINE · LIGHTGBM · ONNX · C++ · PYTHON

LEAD · ApJS
  • High-performance storage: designed a one-table-per-source model with HEALPix indexing on TDengine — 48M rows ingested in 33 seconds; cone search improved from a 15-second full scan to 50 ms.
  • Lightweight inference: replaced a 21.8 GB random forest with LightGBM exported to ONNX — 87× smaller, memory below 10 MB, and 93.6% accuracy without a GPU.
  • Incremental triggering: confidence filtering re-classifies sources as new data arrives; high-confidence results can emit at 50% curve completeness.
